# Free learning resources — recommended order

Use the resources in this order. Do not try to complete every resource cover-to-cover; follow the relevant topic for the current week.

## 1. Main System Design curriculum
1. [Free System Design](https://freesystemdesign.com/) — guided, hands-on foundations.
2. [System Design Primer](https://github.com/donnemartin/system-design-primer) — broad reference and interview problem collection.
3. [ByteByteGo System Design 101](https://github.com/ByteByteGoHq/system-design-101) — visual explanations and architecture patterns.
4. [Hello Interview — System Design](https://www.hellointerview.com/learn/system-design/in-a-hurry/introduction) — interview structure and worked examples; use free material only.

## 2. Distributed systems and backend depth
- [MIT 6.5840 Distributed Systems](https://pdos.csail.mit.edu/6.824/) — lectures and labs; challenging, so select topics relevant to the roadmap.
- [Martin Kleppmann's DDIA resources](https://dataintensive.net/) — book companion material. The full book may not be free; do not assume it is.
- [Apache Kafka documentation](https://kafka.apache.org/documentation/)
- [Redis University](https://university.redis.io/) — check available free courses.
- [Hussein Nasser on YouTube](https://www.youtube.com/@hnasr) — backend, networking, databases.

## 3. LLD and coding design
- [Refactoring Guru](https://refactoring.guru/design-patterns) — design patterns.
- [Awesome Low Level Design](https://github.com/ashishps1/awesome-low-level-design) — curated LLD material and exercises.
- [Arpit Bhayani on YouTube](https://www.youtube.com/@arpitbhayani) — system design and engineering discussions.

## 4. Reliability and production engineering
- [Google SRE Books](https://sre.google/books/) — free online books.
- [Amazon Builders' Library](https://aws.amazon.com/builders-library/) — production engineering articles.
- [OpenTelemetry docs](https://opentelemetry.io/docs/)
- [Grafana docs](https://grafana.com/docs/)

## 5. Infrastructure
- [Docker Get Started](https://docs.docker.com/get-started/)
- [Kubernetes Basics](https://kubernetes.io/docs/tutorials/kubernetes-basics/)
- [GitHub Actions docs](https://docs.github.com/en/actions)

## 6. DSA
- [NeetCode roadmap](https://neetcode.io/roadmap) — roadmap and selected free explanations.
- [LeetCode](https://leetcode.com/) — free problems; paid features are optional.
- [VisuAlgo](https://visualgo.net/en) — visualise data structures and algorithms.

## Video channels
- [Gaurav Sen](https://www.youtube.com/@gkcs) — system design concepts.
- [Hussein Nasser](https://www.youtube.com/@hnasr) — backend internals.
- [NeetCode](https://www.youtube.com/@NeetCode) — DSA explanations.

**Free-only rule:** Prefer official docs, open-source repositories, free lessons, and free problem sets. Some sites have paid courses or premium features; this roadmap does not require buying them.
