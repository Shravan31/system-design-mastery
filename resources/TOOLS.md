# Free tools for practice

- Diagrams: [diagrams.net](https://www.diagrams.net/) or [Excalidraw](https://excalidraw.com/)
- API testing: [Postman](https://www.postman.com/) free tier or `curl`
- Load testing: [k6](https://k6.io/) open-source CLI
- Containers: [Docker](https://docs.docker.com/get-started/)
- Local Kubernetes: [kind](https://kind.sigs.k8s.io/) or [Minikube](https://minikube.sigs.k8s.io/docs/)
- Metrics and dashboards: [Prometheus](https://prometheus.io/docs/introduction/overview/) and [Grafana](https://grafana.com/docs/)
- Distributed tracing: [OpenTelemetry](https://opentelemetry.io/docs/)
- Version control: [Git](https://git-scm.com/doc) and GitHub

Start with the smallest toolset needed for a project. Do not add Kubernetes, Kafka, or multiple databases just to make a diagram look impressive.
