# Books and reading

A genuinely free-only plan should not depend on purchasing books.

- Use the freely available companion resources for *Designing Data-Intensive Applications*: https://dataintensive.net/
- Use Google's online SRE books: https://sre.google/books/
- Use official documentation and open course notes as your primary reading material.
- If you already have legal access to a technical book through a library or subscription, use it as supplementary reading.

Do not spend weeks collecting reading lists. Read for the current week's learning objective, then apply the concept.
