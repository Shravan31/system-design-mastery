# Project portfolio

The purpose of projects is to prove that you can apply design concepts, not to build production-scale clones.

Recommended order:
1. URL Shortener — Weeks 1–4.
2. Notification Service — Weeks 5–8.
3. Chat Application — Week 9.
4. News Feed — Week 10.
5. Video Platform — Week 11.
6. Ride Booking — Week 12.
7. LLD exercises — Weeks 13–16.
8. Payment System — Weeks 17–20.

For each project, include:
- Problem statement and assumptions.
- Functional and non-functional requirements.
- Capacity estimates.
- API contracts and data model.
- Architecture diagram.
- Critical request / event flows.
- Failure scenarios and mitigations.
- Trade-offs and alternatives.
- What you would change at 10x scale.
